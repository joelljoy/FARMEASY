# 🌾 FarmEasy

## Smart Agriculture Marketplace Platform

FarmEasy is a full-stack AgriTech platform designed to digitally transform the agricultural ecosystem by connecting farmers, landowners, equipment providers and buyers through a unified marketplace.

The platform enables users to lease agricultural land, rent farming equipment, trade agricultural products, discover government schemes and access AI-powered farming assistance while maintaining secure and transparent transactions.
